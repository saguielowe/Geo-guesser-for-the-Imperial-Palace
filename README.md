本项目「寻迹故宫」（Tracing the Forbidden City）以故宫官方数字全景资源为
基础，实现了一款GeoGuessr 风格的360° 定位游戏。玩家观察全景画面，在离线故
宫平面图上点击猜测所在位置，系统按误差计分并展示建筑知识。项目采集40个场
景锚点（游玩时可在线下载更多），覆盖故宫11个建筑区域，通过仿射变换校正在地坐标；前端集成krpano全
景引擎与Leaflet 宫图交互，后端以Python 提供本地服务与资源管理，并打包为独
立桌面应用。在技术实现之外，锚点标定、知识题目撰写与全景观察的过程本身即构
成了一种沉浸式的故宫空间学习体验。详见课程报告 report.pdf。
