## 一、核心代码（在 GitHub 基础上改过的）

### `backend/server.py`
- **场景清单**：优先 `scene_catalog.demo_anchors.local.json`（不再优先 demo10）。
- **资源 API**：`/api/resources/status`（含 `?usage=1`）、`/prefetch`、`/prune`、`/refresh` 等。
- **宫图路径**：静态资源指向 `data/raw/leaflet/tiles`（不是 `assets/map`）。
- **知识库**：提供 `/api/knowledge`，读取 `data/processed/scene_knowledge.json`。
- **配置/健康检查**：`/api/config`、`/api/health` 等返回本地可玩数、catalog 模式等（供前端顶栏统计）。

### `backend/resource_manager.py`（新文件或本会话大幅新增）
- 后台下载队列（复用 `scripts/phase0_bulk_tiles.py` 逻辑）。
- **prefetch 策略**：优先已锚点/有 pixel 的场景，其次非夏季等。
- **prune 策略**：按 MB 或场景数清理，**保护已锚点场景**。
- **占用统计**：`pano_mb` + `other_mb`（**宫图并入 other**，不再单独 `map_mb`）；120s 缓存；避免首屏全盘扫描 `data/raw`。

### `frontend/app.js`（改动最多，约 2200+ 行量级）
- **游戏模式**：`GAME_MODE`；隐藏 leak 信息；计分板 2×2（本题/题号/累计/平均分 `xxxx/5000`）；游戏模式**隐藏误差距离**。
- **真值优先级** `getSceneTruthCoord`：`click_pixel_xy` → `user_x/y` → catalog 回退。
- **计分** `scoreByDistance`：分段 knots（≤5 → 5000 等）；`animateScoreDisplay`。
- **满分特效（方案 B）**：`score >= 5000` → 金边、地图涟漪、横幅、纸屑、Web Audio chime；报告模式默认静音，`?sound=1` 开声。
- **回合流程**：提交 → 季节小问（概率）→ 建筑小问 → 下一题；`local-only` 随机；低题量 prefetch。
- **报告模式** `?report=1`：隐藏 ⚙、停 prefetch、改副标题/版本文案、六景按钮 `REPORT_FIGURE_SCENES`。
- **设置面板**：懒下载、磁盘预算、占用显示（全景 / 其它 / 合计）、清理。
- **常量**：`PERFECT_SCORE=5000`，`REPORT_FIGURE_SCENES`（太和殿、中和殿、保和殿、箭亭、神武门、天一门）。

### `frontend/index.html`
- 布局：左全景+计分，右宫图+问答。
- 计分区 `id="score-board"`，版本 **1.0**。
- 设置面板（⚙）、季节/建筑问答区、`next-round-btn`。
- `report-figure-nav`（报告六按钮，默认 hidden）。

### `frontend/styles.css`
- `.score-board`、compact 计分样式。
- 设置面板 `.settings-fab` / `.settings-panel`。
- 报告模式 `.is-report-mode`。
- 满分特效：`.is-perfect`、`.perfect-toast`、`.perfect-confetti`、`.perfect-map-ring` 等。
